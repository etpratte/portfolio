Character Identification Neural Network

2026

Developed a character recognition neural network from scratch using backpropagation calculus to update weights and biases across the network. The network is structured as layers of nodes, including input, hidden, and output layers, with ReLU and sigmoid activation functions applied to introduce nonlinearity between them. Input images are preprocessed through a custom UI and normalization function before being passed into the network for classification. The model was trained on a dataset of over 60,000 handwritten characters, allowing it to generalize and accurately identify unseen handwritten input.

3D Graphics Engine

2025

Developed a rudimentary 3D graphics engine from scratch using linear algebra to perform geometric transformations and perspective projection. The engine represents objects as collections of 3D vertices in memory and applies transformation matrices to translate, rotate, and scale them within the world coordinate system. These transformed vertices are then projected onto a movable camera plane using perspective projection based on a configurable FOV parameter. The camera system allows the viewpoint to move and rotate within the scene, dynamically updating the projection of objects onto the viewing plane to simulate a navigable 3D environment.

Maze Generation and Pathfinding Algorithm

2025

Programmed a customizable maze generator capable of producing an infinite number of randomly generated mazes. Implemented a pathfinding algorithm using Breadth-first Search (BFS) to compute the shortest path through each maze. The system includes a visual representation that displays the maze structure and dynamically illustrates the pathfinding and solution path.

Orbital Physics Simulator

2025

Programmed an orbital physics simulator that models multi-body gravitational systems using Newton's law of universal gravitation. The simulator calculates forces between any number of bodies to update acceleration, velocity, and position over time, enabling realistic orbital and suborbital trajectories. A visual rendering system displays the motion of bodies in real time, supporting layered orbital structures such as moons orbiting planets that orbit stars.
